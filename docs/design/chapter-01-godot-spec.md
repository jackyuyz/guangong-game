# 第一关：东岭关（Godot 原型规格）

更新：2026-11-16。状态：待实现、待试玩。本文件是第一关当前的开发依据；旧 v1.1 文档保留为设计参考，其中 Phaser、React 和 TypeScript 实现不再作为本关要求。本文为组内工作方案，不表示老师或全组已确认。

## 1. 玩家体验

关羽护送甘夫人、糜夫人寻刘备，来到东岭关。孔秀要求通关文书，双方发生冲突；关羽击败孔秀后，守军退让，一行继续前行。

第一次游玩目标约 6–9 分钟，实际时长通过原型试玩调整。玩家沿一条地面左右移动，学习攻击和闪避，再应对孔秀的长枪。背景中的夫人和马车交代出行目的，不设护送血条。

第一关采用横版 2D 场景。暂不加入跳跃、上下走位、骑马、装备、随机掉落或经验系统。

## 2. 完整流程

| 顺序 | 画面与互动 | 完成条件 |
|---|---|---|
| 1 | 主菜单：开始、设置、文化说明；已有通关记录可查看或重玩 | 点击开始 |
| 2 | 2–4 幕开场：人物关系、寻兄目的、来到关口；字幕和配音，可跳过 | 播放完毕或跳过 |
| 3 | 移动教学：走到旗标 | 到达旗标 |
| 4 | 攻击教学：击打训练靶 | 2 次有效命中 |
| 5 | 闪避教学：躲一次带明显预警的示范突刺 | 闪避成功；反复失败提供提示和跳过教学入口 |
| 6 | 第一波 2 名守军，依次靠近 | 全部击败 |
| 7 | 第二波 3 名守军，最多 2 人同时准备攻击 | 全部击败并抵达城门 |
| 8 | 孔秀战前对白，可跳过 | 对白结束，建立 Boss 检查点 |
| 9 | 孔秀 Boss：突刺、横扫，半血后增加连招 | 孔秀 HP 归零 |
| 10 | 守军停止进攻、放下武器或退让，关口放行 | 演出结束或跳过 |
| 11 | 结尾旁白、简短文化回顾、结算与保存 | 返回菜单或重玩 |

过场、暂停和失败界面期间不接受战斗输入。跳过对白须停止当前配音。切走浏览器标签页时自动暂停。

## 3. 场景和操作

逻辑画布暂定 960 × 540；世界宽度暂定 3400。依次划分教学区、第一波守军区、第二波守军区、城门 Boss 区，边界通过试玩调整。

镜头横向跟随关羽，进入 Boss 区后限制在该区域。使用远山、城墙和前景等 2–3 层画面表现景深，不要求 3D。顶部显示关羽血量、暂停入口；Boss 战显示孔秀血条。

| 按键 | 动作 |
|---|---|
| A/D 或左右方向键 | 左右移动 |
| J | 单次挥刀；在接段窗口再按可接最多三段，按住不自动连打 |
| Space | 朝当前移动方向闪避；无方向输入时朝面向方向闪避 |
| Enter | 推进对白、确认互动 |
| Esc 或 P | 暂停和恢复 |

鼠标在游戏内显示为刀尖朝左上、刀刃朝左下的青龙偃月刀，原图缩放为 0.65 倍，静止时刀尖对齐鼠标位置。左键按下可用按钮时，以刀柄后段握持处为轴，先轻抬，再让刀头向左下划弧劈下，随后收回，合计约 0.2 秒。淡金刀光沿刀头的下劈轨迹展开。点击由原生界面按钮按真实鼠标位置处理。

## 4. 战斗初始参数

以下为调试起点，不是已经验证的平衡结果。

| 对象 | 参数 |
|---|---|
| 关羽 | 6 格血；移动 215 px/s；三段攻击伤害 1/1/2 |
| 关羽受击 | 无敌 800 ms，轻微击退、闪烁和短暂停顿反馈 |
| 闪避 | 总长 360 ms，中段无敌 220 ms；从起手算冷却 800 ms；期间不能攻击 |
| 普通守军 | 每人 2 HP，伤害 1，移动 90 px/s |
| 守军攻击 | 前摇 600 ms、命中窗 160 ms、后摇 650 ms；下一次主动攻击间隔 900–1400 ms |
| 孔秀 | 16 HP，伤害 1，移动 110 px/s；HP ≤ 8 进入第二阶段 |

攻击判定和身体受击判定独立；一次挥砍对同一敌人只造成一次伤害。敌人出招前必须有姿势、方向提示和声音等可读反馈，不能只依赖颜色。Boss 不得被连续攻击永久打断。

| 孔秀招式 | 第一阶段 | 第二阶段 | 玩家应对 |
|---|---|---|---|
| 突刺 | 前摇 650 ms，命中窗 180 ms，后摇 800 ms | 前摇缩至 550 ms | 后撤或闪避，收枪时反击 |
| 横扫 | 前摇 900 ms，命中窗 240 ms，后摇 1000 ms | 前摇缩至 780 ms | 看准蓄力提示闪避 |
| 突刺接横扫 | 无 | 每 3 次出招中最多 1 次，两次判定之间至少留 450 ms | 连续躲招后反击 |

胜利优先：孔秀 HP 归零时立即停止所有敌方伤害，再播放胜利演出。场边保留 1–2 名非进攻型守军用于退让演出。

## 5. 检查点和失败重试（本次调整）

两波守军通过后、战前对白结束时，在当前会话中建立 Boss 检查点。进入 Boss 战时，关羽若不足 4 格血，补到 4 格；若高于 4 格则保留。记录此时的血量、已完成清兵阶段的战斗时间和受击次数。

- 清兵阶段失败：默认从第一波守军重试，恢复 6 格血，重置本轮战斗统计，不强制重做教学或开场。
- Boss 阶段失败：默认按钮为「重试孔秀」，直接进入 Boss 战，不重打守军、不强制重听对白。
- 重试孔秀时：关羽恢复检查点血量，孔秀恢复 16 HP 和第一阶段；双方位置、攻击、冷却和临时特效重置。
- 恢复检查点统计，丢弃失败的 Boss 尝试产生的时间与受击；重试次数单独累加。成绩统计成功路径，并明确展示重试次数。
- 失败界面另有「从第一波重来」和「返回菜单」。前者清除 Boss 检查点，按清兵重试规则处理。
- 检查点只在当前关卡会话有效。退出到菜单或刷新页面后不保留半途进度；退出确认必须说明这一点。持久保存的设置、已有通关和最佳成绩不受影响。

## 6. 文化内容与文本组对接（本次调整）

开场先让新玩家知道关羽是谁、两位夫人与他的关系，以及为什么要寻刘备。战前对白交代通关文书与同行者的冲突；结尾回顾关羽坚持护送同行者的选择，并引导玩家理解本段故事中的「忠」「义」。避免把战斗胜利本身等同于道德正确。

通关后展示一张可跳过的文化回顾卡：简短故事回顾、关键词释义，以及「本游戏改编自《三国演义》，并非对历史事件的复原」的说明。该说明也能从主菜单文化说明中查看，跳过卡片不会阻止通关保存。

文本组对接内容：

| 内容 | 需要提供或核对的材料 |
|---|---|
| 开场、战前、结尾 | 审定后的中文文本及英文翻译、繁体、拼音 |
| 文化回顾卡 | 人物关系、忠义解释及文学改编说明 |
| 选择题（预留，P1） | 从该关已审定题库挑选 1–2 道，带选项、正确答案和解释 |

题库尚未接入，不编造已经收到的材料。选择题为可选复习入口，不作为过关条件、不影响战斗评分；第一版允许暂不实现。正文、字幕和题目采用独立文本数据，不能画死在图片上。示例对白只能标为草稿，不能称作小说原文。

文字提供简体、繁体、英文和拼音；配音为普通话、英语两套。开场、战前、结尾支持跳过与重播，同一时刻最多播放一段叙事配音。缺配音可先验证字幕流程，但不能声称配音已交付。

## 7. 结算和保存

只统计战斗时间，不计教程、对白、暂停或文化卡。Boss 重试按第 5 节恢复统计。

沿用原型评分公式：

`score = 600 + floor(240 * remainingHP / 6) + floor(160 * clamp(1 - max(0, combatSeconds - 180) / 360, 0, 1))`

仅在通关时计分，展示分数、战斗时间、剩余血量、受击次数和重试次数；评分版本标为 `ch01-v2-checkpoint`，旧评分记录保留为旧版，不与新版直接比较。

保存语言、音量、通关状态及同评分版本下的最佳成绩、时间。通关先保存再展示可跳过的文化回顾和结算，不因跳过卡片丢失记录。第二关未上线时只显示「即将推出」。

## 8. Godot 实现范围

工程位于 `godot/`，采用 Godot 4 + GDScript，Compatibility 渲染器，以桌面键盘游玩为首要目标，导出单线程 Web 版本。手机端先保证菜单可读并提示使用桌面键盘。

场景、脚本、文本数据和运行时素材放入工程内；`assets/art/` 是仓库素材库，选取需要的文件复制到 `godot/assets/`。静态立绘和完整概念场景不能算作已经完成的战斗动画；须补足侧视动作和可横向展开的场景层。

先完成以下顺序，每步实际运行后再扩展：

1. 东岭关背景、关羽移动、镜头跟随，并验证 Web 导出。
2. 攻击、闪避、命中和受击反馈，再加入两波守军。
3. 孔秀两阶段战斗、检查点、失败重试和胜利退让。
4. 教程、剧情、文化卡、多语言与音频、结算和保存。
5. 替换临时素材，检查桌面 Chrome、Safari 的输入、加载、声音和保存。

第一版不做其他四关、账号、云存档或排行榜。网页文化站点与游戏工程分别开发，通过链接或嵌入接入。

## 9. 验收重点

- 新玩家可完成「开始 → 剧情 → 教学 → 两波守军 → 孔秀 → 退让 → 保存 → 文化卡/结算」。
- 清兵失败从第一波重试；Boss 失败直接重试孔秀，血量与统计按检查点恢复；失败招式和音频不残留。
- 返回菜单或刷新清除临时检查点，设置和已有通关保留；重复通关不清掉最佳成绩。
- 孔秀死亡后无残余伤害，暂停和失焦停止战斗计时；一次攻击不会重复扣血。
- 文化卡可跳过或从菜单重读；跳过不影响保存。若后续接入题目，答错只提供解释，不回退战斗进度。
- 四种文字显示正常，两套配音无叠音；缺失素材或配音如实记录。
- 正式宣称 Web 可玩前，实际在浏览器验证完整流程。
