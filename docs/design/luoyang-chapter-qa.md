## 复现

在仓库根运行 Godot 4.7.2：

```sh
"$GODOT" --headless --path godot --script scripts/luoyang_chapter_test.gd
python3 tools/luoyang_prototype.py --chapter --export --godot "$GODOT"
python3 tools/luoyang_prototype.py --chapter --serve
```

打开 [完整玩法原型](http://127.0.0.1:8973/)。A/D 或左右换道，P/Esc暂停，R重试当前可操作段，Enter继续剧情和文化页，M切换声音。该独立入口不写旅程记录；正常工程从旅图进入才由宿主保存。
