## 复现

在仓库根目录运行，`GODOT` 指向 Godot 4.7.2：

```sh
"$GODOT" --headless --path godot --script scripts/luoyang_prototype_test.gd
python3 tools/luoyang_prototype.py --export --godot "$GODOT"
python3 tools/luoyang_prototype.py --serve --port 8972
```

打开 [本机原型](http://127.0.0.1:8972/)。A/D 或左右换道，P/Esc 暂停，R 重试本段，M 静音。原生直接运行可用 `python3 tools/luoyang_prototype.py --godot "$GODOT"`，或在正确工程中打开 `scenes/prototypes/luoyang_prototype.tscn` 后运行当前场景。
