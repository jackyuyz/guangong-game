# 关羽致命受击与失败演出

2026-11-24。用户要求关羽血量归零后可看到完整倒地，以及孔秀最后一次出招；此前归零就切到失败弹窗，会截断双方动作。本规格补充第一关战斗与检查点设计。

## 动作与时序

- 所有敌人的攻击按实际剩余时间驱动动画；0.24秒出招的第0.08秒进入第二帧时才允许命中，单次攻击仍只判定一次。孔秀第三帧保持伸枪，随后用新增八帧收枪衔接待机；普通出招也使用该收枪，弹反／偃月斩打断仍保留原硬直姿态和时长。
- 关羽致命受击当帧立即锁定失败，血量下限为0，进入独立`dying`状态。停留在命中位置，停止双方位移、其他AI和进一步伤害；孔秀保留当前攻击剩余帧，再完整收枪。致命命中后不继续冲刺到关羽身上。
- 关羽播放独立八帧：受击后仰、踉跄、屈膝、跪地、撑地、侧倾接地、侧卧、停稳。按用户反馈修正第6帧为躯干侧倾、腿部伸展及长刀落下的连续过渡，不再使用半跪前扑姿势。约1.0375秒，真实脚底／接地位置按AtlasTexture元数据对齐。
- 原0.06秒命中停顿保留；等攻击者剩余出招＋收枪、关羽倒地都完成，再停留0.28秒，才转为`dead`显示原失败与重试界面。倒地姿势留在背景，不显示敌方预警或继续连招。无攻击者的受击也可安全完成倒地。

## 输入、暂停与保存

`dying`时保留血条归零反馈与暂停／操作指南，禁用战斗操作、对白继续／跳过和提前重试。Esc／P、HUD暂停、失焦与确认退出均冻结双方动作和音频，恢复从同一帧继续；减少动态关闭震屏但不省略动作。

失败演出不累积战斗时长／受击数，不写入通关或分数，不修改原检查点。重试清除倒地与攻击者表现数据，恢复原血量、义气和成功路径统计，保留重试次数；小兵失败仍从第一阵恢复。返回菜单、新开与从第一阵重开清除演出数据。Boss致命伤优先胜利的既有规则保持。
