# 游戏设计

[全游戏武侠设计语言](wuxia-design-language-spec.md) 规定墨绿绢底、旧金笔触、行楷题字与宋体正文的统一方向，并附一张设置页效果图；现有游戏页面已接入共享主题，逐页实现与验证边界见规格第 12 节。

[界面层级与渐进呈现](interface-hierarchy-spec.md) 记录主菜单、旅图、前情和战斗／结算的当前精简方案，以及共用设置、操作指南和模态输入规则。

[东岭关朱红笔触战斗界面](combat-hud-spec.md) 记录用户选定的第二张概念图如何接入气血、义气、孔秀血条与出招预警；[道路与背景分层方案](dongling-ground-layout-plan.md) 分析整幅背景承载横向关卡的问题，尚待实施。

[制作人员页](credits-spec.md) 记录首页第四项入口、制作团队署名、课程说明、致谢及后续成员名单的扩充方式。

[五关旅图与前情回顾规格](five-passes-map-spec.md) 是下一步地图入口的设计依据：山水像素卷轴、顺序解锁、通关重玩、首次前情后选关、地图回顾与旧存档迁移。已接入并通过本机验证；当前仅东岭关可玩，其余四站标为「未解锁」。

[第一关 Godot 规格](chapter-01-godot-spec.md) 是第一关当前的开发依据，包含 Boss 检查点、文化内容对接和验收条件。

[全游戏前情提要](chapter-01-prologue-spec.md) 记录已实现的约 51 秒动态连环画与 ElevenLabs 中文老先生说书配音，包含文学依据、分镜字幕、播放交互、本地凭据、素材来源和 Godot 接入方案。文件名保留旧路径，前情适用于整个游戏；地图入口与回顾返回以新旅图规格为准，字幕仍待正式文本审定。

[GuanGong_WebGame_SPEC_v1.1.md](GuanGong_WebGame_SPEC_v1.1.md) 是原有完整方案，保留原文供查阅。与新规格冲突时，第一关以新规格为准。

## 阅读顺序

- 地图、解锁与前情新路由先读五关旅图规格；战斗与检查点读第一关 Godot 规格。
- 旧文第 4 节：其余四关的故事与玩法概要。
- 旧文第 6 节、第 19.11 节：动作素材制作参考。

## 技术方案状态

原文按 React + Phaser + TypeScript 编写，包含旧目录、API、模块名和开发里程碑。
当前已使用 Godot，原文中的这些技术实现不作为 Godot 开发要求；后续按 Godot 逐项细化。
五关玩法、剧情、第一关战斗规则可作为原型设计参考，数值仍需试玩调整。

原文的 Phase 1–3 是产品开发分期，与课程任务表里的 Stage 1–3 不应直接对应。
文档描述的是计划，不代表功能已经实现，也不代表已得到老师或全组确认。
