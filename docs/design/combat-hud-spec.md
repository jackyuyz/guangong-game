# 东岭关战斗界面 · 朱红笔触

2026-11-24。用户选中聊天中第二张概念图 `docs/art/combat-concepts-2026-11-24/02-cinnabar-brush.png`，要求接入第一关并保留现有人物与场景素材。按该方向实现Godot原生HUD；概念图内重绘的人物、背景与字体不作为替换素材。

## 布局与信息

- 960×540逻辑画布。左上玉牌内显示朝右的关羽像素头肩头像，关羽名称、连续朱红笔触气血条；血量仍是0–6，不引入新资源或伤害规则。
- 血条下四枚金色义气菱形，对应0–4义气；右侧L键帽和偃月斩。只有 `heavy_ready()` 为真才亮起就绪笔触，满义气但尚在冷却时不提示可用。
- 关名在上方居中，操作、声音和暂停为右上轻量文字按钮。教学只显示当前按键；第一／第二阵目标保留，Boss战隐藏重复的击败目标及登场横幅。
- 孔秀血条置于底部中央，金色笔触填充和矛尖端饰；姓名／职衔始终保留，半血后额外标示「奋战」。重要破防、弹反等战斗说明继续出现。
- 仅剩1–2格血时显示短文本「气血不足」。受击血量立即更新，残影延迟0.14秒后消退；回血、重试和减少动态直接呈现。暂停／失焦冻结残影。

## 原生场景与素材

`combat_hud.tscn` 为独立Control场景，血条使用真实TextureProgressBar，文字为Label，按钮保留原生动作接线和战斗鼠标焦点规则。场景布局不由脚本重建，编辑器变换继续有效。

新增玉牌、金色义气菱形、Boss条框及柔墨衬底均为内置image_gen的独立透明素材。血条复用原有金刷并着色；玉牌中心现改为复用关羽原图集首帧的头肩裁取：Atlas区域(180,122,144,180)，40×50逻辑像素，Portrait左上为(13,8)，按用户反馈右移2px以平衡重心，眉眼略高于圆心，圆形遮罩保留玉牌装饰边框。头像静止且始终朝右，最近邻采样，去除原「关」字；未生成或改写原PNG。完整提示见 `godot/assets/ui/combat-ui-creation.json`，来源记录见 `godot/assets/ui/SOURCES.md`。

首轮HUD接入未改角色和关卡；用户随后授权分层道路，现已保留原角色与源素材，重组为连续土路及独立终点关口，详见 [道路与背景分层](dongling-ground-layout-plan.md)。较亮天空下的关名与操作补充局部柔墨衬底，保持可读性。

## 出招预警

原矩形条改为独立 `attack_telegraph.tscn`，仍在敌人真实脚底与真实朝向下显示：突刺为窄箭形，横扫为扇面，颜色之外有形状与文字区分。范围仍取现有守军120／孔秀190，不改变判定；收招、失败重试和敌人离场时清除。提示文字放在敌人外侧，避免持续遮住武器与头部。
