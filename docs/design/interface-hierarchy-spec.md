更新：2026-11-23。界面精简版已提交并发布；键帽指南及第 4 版首页已提交本地 main，尚未推送或发布。本规格补充五关旅图和前情规格；页面文案、控件层级以本文和用户最新决定为准。

后续全局视觉统一见 [武侠设计语言规格](wuxia-design-language-spec.md)。设置页已按该规格接入，其他页面的视觉统一留待后续；本文已实现的信息层级和交互继续有效。

## 产品目标

让玩家一眼知道当前页面要做什么。保留现有卷轴、军旗、金色选中笔触和连环画；依靠留白、主次按钮与按需展开降低信息密度，不增加装饰卡片。删掉开发说明与重复状态，必要说明必须仍可发现。

## 各页面

| 页面 | 默认呈现 | 按需呈现 |
| --- | --- | --- |
| 主菜单 | 游戏名、副题、一句故事引子、启程／继续旅程、故事与文化、设置与操作 | 设置中的声音、减少动态与完整操作指南；保存失败仍直接显示 |
| 五关旅图 | 五站关名与状态、真实旅程军旗、选中笔触、已过关数、选中关卡标题及剧情短句 | 已通关才显示最佳分；使用键盘时显示选关快捷键；设置与操作指南可随时打开 |
| 锁定关卡 | 地图节点显示未解锁，右侧说明前置与尚未开放 | 不重复显示详情状态与禁用出发按钮，不进入空场景 |
| 可玩关卡 | 简介与开始／再次挑战主按钮 | 无成绩时不显示空记录，已有成绩只显示最佳分 |
| 前情 | 标题、首次人物关系说明、画面、字幕、前后翻幕、播放／暂停、幕数、声音、跳过／返回 | 系列名只在首幕；重听本幕收进更多菜单；文学改编说明保留在文化页 |
| 战斗 | 血量、当前目标、必要技能资源与互动提示、操作／声音／暂停入口 | 基础教学逐项显示当前按键；完成后退场；闪避只在冷却时显示状态；暂停与结算不叠加战斗 HUD |
| 失败 | 当前可用重试与返回旅图 | 有 Boss 检查点时才显示从头重来和检查点说明，避免两个同义重试入口 |
| 暂停 | 暂歇片刻、继续前行、设置与操作、返回旅图／菜单 | 不重复解释已经暂停；退出仍确认本局进度将丢失 |
| 结算 | 本次分数、最佳成绩、返回旅图主按钮、故事回顾 | 战绩可展开时间、体力、受击和重试；保存失败仍直接显示 |

## 设置与帮助的行为

- 主菜单、旅图和暂停页共用原生设置面板。战斗中打开操作指南会先暂停，关闭后留在暂停页，由玩家主动继续。
- 声音与减少动态仍通过统一存档保存；减少动态涵盖旅图展开／军旗、前情轻推与转场、战斗镜头抖动，字幕与旁白继续正常播放。
- 设置覆盖旅图时暂停地图动态，恢复窗口焦点也不能使被覆盖的地图提前恢复。
- Tab／Shift+Tab 与上下键在面板可用按钮之间循环，左右键不把焦点送到遮罩背后；关闭时恢复原焦点与地图选择。
- Esc 关闭当前面板，不同时退回主菜单；面板拦截 Enter、战斗键和底层按钮动作，关闭后隔离旧选关输入。
- 完整键位始终可从设置、地图、战斗操作入口或 F1 查看，不能因主页面精简而失去帮助。

## 赤兔征途首页

- 采用用户选中的第 4 张：首页全幅关羽骑赤兔、雄关与曙光，独立飞白书法标题，右侧竖列「启程」「故事与文化」「设置与操作」，移除原大矩形面板。回访玩家主按钮改为「继续旅程」并缩字号以容纳完整文案。
- 背景、标题、说明、按钮为真实可编辑节点。标题为透明图像，副标题／菜单使用 Ma Shan Zheng 的 OFL 子集，正文和其他页面字体保持原样。
- 按钮的文字与周围留白均可点；悬停淡入金色笔触背景、加亮下划线及字体，按下背景更实。悬停 95 ms 短音、确认 160 ms 短音；共享静音生效，75 ms 内的鼠标／焦点重复事件不连响。
- 上下键、Tab／Shift+Tab 在三项间循环；回车和空格确认当前选项，不能穿透到全局启程。键盘焦点有同等视觉反馈。开启减少动态时即时切换，无淡入；失焦、隐藏或设置／文化覆盖时停止菜单反馈。
- 启程仍遵循首次前情到旅图、回访直接旅图的既有流程；故事、设置和完整操作指南仍可用，保存失败提示保留。

## 键帽操作指南

- 用墨绿面板、旧金边缘和有厚度的原生键帽呈现完整键位，左右分成行走战斗、旅图菜单两栏；不增加演示说明或第三个底部按钮。
- 键帽有下沉、金色按压和回弹，按 14.6 秒时间轴轮流演示；J 连按三次表达三段连击，Space 使用长键帽。演示只改变显示，不能产生输入、推进战斗或写存档。
- 减少动态开启时所有键帽静止；窗口失焦或指南隐藏时不推进演示，关闭再打开从头开始。原有暂停、焦点恢复和模态输入隔离保持生效，保存失败仍可见。
- 布局与标签保存在 `keyboard_guide.tscn`，键帽层次和按压轨道保存在可复用的 `guide_keycap.tscn`，可在 Godot 2D 与 AnimationPlayer 中调整。沿用现有字体，无新增图片素材。

## 前情更多菜单

打开时同步暂停镜头、幕内计时与三路声音。点击重听关闭菜单并从当前幕起点重新播放；关闭菜单或按 Esc 恢复此前自动／手动阅读状态，不将手动阅读擅自改为自动播放。外部点击只关闭菜单，不穿透触发翻幕或跳过。字幕、声音受阻与静音提示保留。
