# 东岭关最后一击与孔秀倒地

2026-11-24，按用户确认的「踉跄后侧身倒地」实现。本规格替代旧的致命伤后立即清空人物、重置攻击并弹出结尾的行为；数值、检查点和原场景布局沿用现状。

## 顺序

1. J先播放起手，第0.08秒进入第二攻击帧后才命中；L第1/9秒命中。每次攻击对每名敌人只结算一次。L仍在起手时检查范围并消费四点义气，命中时按实际范围判断；起手时没有目标则保留义气。
2. 致命命中当帧优先锁定胜利、分数与成功路径统计并保存一次，进入独立`finishing`状态。孔秀与其他敌人不能再伤害关羽；只保留无战斗能力的孔秀表现数据，停止战斗计时。此时不显示对白或结算。
3. 保留原命中停顿（J 0.035秒、L 0.07秒）、刀光及攻击剩余帧；关羽伸刀尾段结束后接0.5秒八帧收招，回到待机。孔秀同时播放八帧踉跄、屈膝、侧倒、肩部触地、侧卧，约1.0875秒。保留原节点位置与比例，逐帧修正接地基线，左右朝向均可。
4. 两人动作均完成后，再保留0.28秒倒地停留；之后进入现有两句结尾草稿对白，再到文化卡及通关界面。孔秀保持侧卧，不重新出现战前立绘或预警；镜头继续固定关口，结束前不出现撤退守军。

## 输入、暂停与恢复

演出期间忽略J／K／L／Space／移动及过期的继续／跳过动作。Esc／P、HUD暂停与操作指南仍可暂停；失焦自动暂停。逻辑时间统一驱动攻击、收招与倒地帧，暂停、确认退出和命中停顿均不推进，恢复从同一帧继续。声音也暂停。减少动态保留动作帧、关闭震屏。

失败重试、新开关卡或返回菜单清除收尾数据和遗体；检查点的血量、义气和统计恢复规则不变。动作长度读取场景SpriteFrames，后续编辑帧时长会同步延后结尾，不单靠写死等待时间。
