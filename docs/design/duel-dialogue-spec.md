# 孔秀登场前双人对白

2026-11-24。用户要求清兵后的关羽／孔秀交流同时显示人物，采用类似回合制对战的左右对峙构图。本机实现，未提交、推送或公开发布。

## 呈现

- `duel_dialogue.tscn`为真实Control场景，复用原共享主题。55%单层背景衬暗，下方保留说话者、正文、跳过和继续；960×540逻辑布局。
- 关羽在左面向右，孔秀在右面向左，复用现有动画图集首个idle帧，443.5×443.5 AtlasTexture，最近邻采样。未新增美术、改动角色身份或声称有独立说话动作帧。
- 两人始终同时存在；说话者提亮并略抬高，脚下金线和正文姓名共同指示。入场0.24秒淡入并从外侧滑入28px，减少动态直接显示。暂停／失焦冻结，确认返回弹窗不重置进度。
- 教学、小兵、伤害和义气规则保持。phase5对白时隐藏场景小关羽，避免重复；大立绘不属于敌人列表、不参与战斗。镜头在对白与Boss战均朝门前终点取景。

## 流程

原三句草稿、顺序和文本不改；点击继续或Enter切换，跳过／最后一句结束走原Boss初始化，只生成一个敌人并保存原检查点。对话结束后恢复场景人物与HUD；失败重试仍绕过登场对白。过关后的收尾对白、开篇资源故障后备不显示双人对峙，避免战败孔秀重新出现。旧对话按钮事件在非对白状态不再执行。
