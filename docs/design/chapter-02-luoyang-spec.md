# 第二关：洛阳 · 追孟坦，躲韩福

更新：2026-11-27。状态：完整玩法已接入本机源码与旅图，像素骑乘／斩将、佯退回马、岔口逃脱和束伤车仗离关均已整合；当前界面与正式网页验收见第21节，节奏与难度见第20节，美术／剧情增补见第16–19节，第15节保留第二步几何原型快照，初版操作练习保留在第14节。用户已选择**方案一：固定斜后方镜头的 2D 伪透视三车道骑马追逐**。方案二横向三路完整保留供后续比较，不安排同时开发两种玩法。

本文件是第二关后续开发的设计依据，细化并替代[旧总设计](GuanGong_WebGame_SPEC_v1.1.md)第 4 节中洛阳关的简要描述。已确认的是视角与玩法方向，用户已认可初版操作手感并授权继续完整玩法原型；具体平衡及演出仍需试玩，不表示老师或全组已审定。公开版本仍为东岭关，本机源码已开放通关东岭关后进入洛阳原型，后三关仍不可进入。

## 1. 体验目标与范围

第一关侧重步战、攻击距离和格挡；第二关侧重骑马的速度感、观察前路、换道和追赶。玩家应清楚感到：赤兔比孟坦的坐骑更快，成功避障让关羽逼近敌人；韩福通过伏箭制造不同于固定障碍的危险；关羽负伤后仍能冲门斩将。

- 自动前进，左右换道；两名守将依次构成追击与躲箭阶段，不要求两套长血条近战 Boss。
- 目标为约 1–2 分钟的成功路线，不含阅读文化卡、主动暂停和失败重试；熟练玩家可更快，最终时长以试玩为准。
- 首版只要求换道操作，追上孟坦与冲到韩福处均自动挥刀；暂不增加 J 限时按键、跳跃、滑铲、主动加速、格挡、义气技能或道具收集。
- 使用 Godot 4.7.2、GDScript、Compatibility 和单线程 Web；道路、人物、城门均以可编辑的真实 2D 场景节点组织，不引入完整 3D 场景。
- 夫人与马车在开场和过关后交代，不跟随关羽进入高速追击，不设置护送血条。

## 2. 两个版本与选择依据

| 项目 | 方案一：斜后方伪透视三车道（已选） | 方案二：横向卷动、上中下三路（备选） |
|---|---|---|
| 视角 | 镜头固定在关羽斜后方，道路向远处收窄 | 镜头从侧面观看，道路向左卷动 |
| 位置关系 | 关羽在近景，孟坦在前方；追近后孟坦变大、距离缩短 | 关羽偏左，孟坦在右前方；两者前后距离直接可见 |
| 操作 | A/D 或左右键切换左中右三道 | W/S 或上下键切换上中下三路 |
| 速度感 | 路面与障碍迎面接近、放大，城门逐渐逼近 | 近处地面快速后退，远景慢移，马匹起伏、尘土和追赶距离配合 |
| 固定障碍 | 从远处辨认位置，在到达前换道 | 观察画面右侧的拒马，提前换到另一条路 |
| 箭矢 | 从前方城门方向射来，依靠瞄准、发射与箭路判断时机 | 箭从右侧飞入，横向轨迹较容易辨认 |
| 斩将演出 | 背后视角易遮住武器，需要专门安排并骑与短侧面特写 | 侧面可直接展示两匹马、长刀挥出及敌人落马 |
| 素材适配 | 现有侧面人物与马主要作造型参考；需新增斜背面骑乘、奔跑及匹配道路 | 可更多复用现有侧面人物、马匹和横向场景，但仍缺骑乘动作 |
| 制作重点 | 透视一致、远近缩放、判定时机、迎面箭可读性 | 道路连续、三路区分、遮挡层级、马匹奔跑及距离反馈 |
| 主要风险 | 把静态侧面图缩放成背面跑酷；障碍已到身前才看清；挥刀被身体遮挡 | 看起来像角色静止而背景平移；三路像独立平台；近处角色挡住远路 |
| 最适合突出 | 骑马向前冲、前路危险和临场反应 | 人物形象、追赶关系和马上斩将 |

**选用方案一的原因：**用户希望采用接近三车道跑酷的前进体验，让第二关在观察方向和空间感上明显区别于东岭关。接受为此补做匹配视角的美术和动画。参考《神庙逃亡》的前路可读性与换道方式，不复制其场景、界面或素材。

方案二的保留设计：同样采用“避拒马追孟坦 → 斩孟坦 → 暗箭负伤 → 躲箭冲门 → 斩韩福”的流程、自动攻击和检查点原则；道路改为横向连续官道，三路用地面深度与马蹄阴影表达，按接地点排序遮挡。追击时以两马横向距离反馈得失，韩福瞄准某一路后固定箭路。须专门处理远路箭矢被近景马匹遮住的情况，失败判定与危险提示不能藏在遮挡后。此方案不与第一条混用视角，也不作为已选方案素材不足时的自动替换；若改选，应先更新本节决策。

## 3. 文学依据与改编边界

对应[《三国演义》第二十七回](https://ctext.org/wiki.pl?chapter=934450&if=en&remap=gb)：孟坦佯败引关羽追击，反被快马追上斩杀；关羽勒马回来时，韩福从门首射中其左臂，关羽随后奔向韩福将其斩杀，束伤继续前行。这是文学故事改编，不作为历史复原。

三车道、连续拒马、反复射箭和阶段检查点是为游戏操作加入的改编。原著的暗箭负伤与可操作阶段的躲箭明确区分：玩家躲开所有可躲箭矢，也不改变一次剧情中箭；剧情中箭不算操作失误。

本关开场只交代阻路、孟坦出战并佯败。不要提前向玩家完整揭示韩福的伏击计划。对白、旁白和文化卡后续由文本组审定；本规格不提供已审定台词，也不默认新增配音。

## 4. 完整流程（方案一）

| 顺序 | 画面与互动 | 转换条件 |
|---|---|---|
| 1. 洛阳关前 | 建立城门、韩福、孟坦与关羽的关系；马车停在安全处；短对白可跳过 | 对白结束或跳过 |
| 2. 佯败与起跑 | 孟坦短暂接战后拨马逃走，镜头转入关羽斜后方；自动起跑 | 进入换道教学 |
| 3. 低压教学 | 中道起步，提示左右换道；先单障碍、后另一侧障碍，不计追击倒计时 | 已完成至少一次向左和向右的有效换道 |
| 4. 追孟坦 | 孟坦始终在前方可见；避拒马缩短距离，撞击使距离拉开 | 达到追上距离；或血量归零／孟坦逃脱 |
| 5. 斩孟坦 | 清空交互危险，短暂并骑、侧面挥刀，孟坦败落；自动结算此阶段 | 演出完成或跳过 |
| 6. 回马与暗箭 | 以短镜头交代关羽回马、城门重新位于冲刺前方；韩福从门边放箭，左臂负伤 | 剧情事件恰好结算一次，进入检查点 |
| 7. 带伤冲门 | 回到同一套斜后方镜头；先示范一次有清楚预兆的射箭，再进入连续躲箭 | 到达城门前收尾点；或血量归零 |
| 8. 斩韩福 | 移除未结算危险，切短侧面特写，关羽策马挥刀击败韩福 | 胜利已锁定，演出完成或跳过 |
| 9. 束伤过关 | 关羽束伤，夫人与马车继续前行；文化回顾与结算可跳过 | 保存通关并返回旅图 |

回马在受控镜头中完成，不增加反向操控或第二套道路控制。剧情镜头内不生成新的交互危险。两次挥刀特写结束后只允许进入各自唯一的后续状态。

## 5. 镜头、道路与操作

### 5.1 画面组织

- 镜头固定在关羽斜后方，能辨认赤兔背部、关羽绿袍和刀的轮廓；轻微俯视便于看到前方地面，避免马匹身体挡住全部判定区域。
- 关羽在画面下部，保留马蹄和阴影；三道在远方汇聚。车道以土路车辙、地面层次和路肩表达，不铺现代道路标线或三条悬空跑道。
- 障碍、孟坦、城门共享同一道路透视。远处障碍只有进入可靠辨认的距离后才开始计算反应时间。
- 城门是明确的目标地标。孟坦引关羽离城追逐时，城门留在镜头后方，不显示在前路；回马镜头交代转向后，城门才重新出现在冲门前方并逐渐逼近。侧面镜头始终保持城门在左、追逐向右、返程向左。
- 路边旗帜、树木、尘土和分层移动增加速度感；背景装饰不伪装成可碰撞障碍，不遮住箭路或拒马空隙。
- 具体画布、地平线和锚点以当前工程实际布局为基础，经原型确定后写入 TSCN；不继承第一关旧规格中未经核对的画布数值。

### 5.2 输入

| 输入 | 第二关作用 |
|---|---|
| A/D 或左右方向键 | 向相邻车道换一次道 |
| Enter | 推进对白；明确可跳过的演出按统一界面规则跳过 |
| Esc/P、暂停按钮 | 暂停／恢复或打开既有暂停界面 |
| M | 沿用全局声音开关 |

每次有效按下只移动一条道，忽略键盘自动重复；按住不连续横跨三道。左右同时按下不移动；最外侧继续朝外按不产生抖动或冷却。换道中最多缓存一次后续有效换道，结束后依次执行；暂停、失焦、演出或失败清除缓存，恢复后需新的按下事件。

换道沿地面平滑横移，暂定每次 0.20 秒，无闪避无敌。物理位置随换道连续变化，不能按键当帧就获得目标道安全，也不能用瞬移跳过途中危险。首版键盘为必需操作；触屏滑动与手机适配不包含在本次规格的首版范围。

教学使用低速、可重复的单拒马练习，不扣操作血量、不惩罚追击距离、不判孟坦逃脱；未完成左右换道时保留简短键帽并继续练习。完成后清除教学障碍，在安全间隔后建立阶段 A 检查点并开始正式追击。

## 6. 阶段 A：追孟坦

### 6.1 追赶规则

- 孟坦是能持续追近的实体目标；安全前进时关羽比孟坦快，距离逐渐缩短。
- 撞拒马造成一次伤害、短促减速，并拉开两马距离；以马蹄、身体起伏和敌人距离变化反馈，不倒放道路或把关羽瞬移回远处。
- 在配置的追上距离内，且当前没有未结算的玩家致命伤时，锁定斩孟坦演出。教学期间不能提前触发斩将。
- 追击有有限路线。路线末段通过孟坦奔向前方岔口及一次短提示交代逃脱风险；到达路线终点仍未追上则失败。最后警示目标至少提前 8 秒可见，不突然黑屏宣告逃脱。
- 路线时长与初始距离必须联调：正常避障约 30–45 秒追上；少量失误有追赶余地；不能设置玩家即使全程正确也追不上的参数。暂定路线最大 65 秒，不含教学、暂停和演出。

### 6.2 障碍与公平性

首版只用鹿角拒马：从单道开始，再出现封住两道、保留一道的组合。拒马碰撞后失去本次碰撞资格，不因角色仍接触同一物件逐帧掉血。

采用手工编排并验证的有限障碍序列，首版不做无限随机跑酷。每组危险都必须从玩家可能到达的位置存在安全路线，计入换道时间、受击减速和缓存规则。不能只检查某一横排留了一条道，却让相邻两排之间来不及换道。暂停恢复和检查点重开也适用同一规则。

近距离追上孟坦时预留清楚的并骑空间，不在其身后藏拒马。进入演出后立即关闭危险结算，不能在挥刀镜头里继续扣血。

## 7. 暗箭与阶段 B：带伤冲门

### 7.1 剧情负伤

暗箭在明确的非操作镜头中发生：韩福出现、弓弦响、关羽左臂中箭、短促受伤反馈。镜头回到操作前给出清楚的重新起跑过渡，不将必中的剧情箭伪装成要求玩家闪避的交互箭。

- 剧情中箭不扣操作血量，不累计可避免受击次数，不降低无伤评价，不导致失败。
- 负伤状态用于骑乘姿态、左臂伤痕／束布、声音和结尾连续性；换道仍保持灵敏。
- 首版不加入持续流血、随机失控、减小视野或负伤后延长换道时间。
- 演出正常播放、跳过、暂停后续播均只写入一次负伤状态，不能重复结算或漏掉伤态。

### 7.2 射箭规则

韩福位于前方门边低位射击处，不放到高楼上而使最终马上斩将无法衔接。射击表现依次为：**拉弓瞄准 → 锁定箭路 → 放箭 → 箭通过玩家所在的纵向位置 → 收弓**。

瞄准阶段跟随玩家当前道，清楚表示尚在追踪；锁定时记录目标道并给予姿势／地面短标记变化和放弦声，之后箭不再追踪。过早换道可能被重新瞄准，锁定后换道才可靠避开。首轮以较长预警示范这一差别。

- 第一类为单箭，锁定一条道；后段可加入相继射出的两箭，每一箭独立瞄准、锁定、预警和判定。
- 首版不发三道同时到达的齐射，不加入无预警侧箭或贴身生成箭。
- 常规箭命中扣一次血并给出受击反馈，不改变关羽已经中剧情箭的次数。箭错过玩家后失去伤害资格，不能在身后再次命中。
- 玩家需要根据箭路闪避，不能依靠单一安全道停到终点。瞄准／发射节奏应让停在任一道都会遭遇交互危险。
- 阶段 B 首版以射箭为主要危险，暂不与阶段 A 的密集拒马同时叠加，保证两阶段节奏有区别。
- 到达门前收尾点锁定胜利，关闭全部敌方伤害并处理剩余箭矢，再播放斩韩福；同一逻辑时刻同时满足到达与箭命中时，胜利优先。更早已经归零并锁定失败的状态不能被后续到达事件改写。

## 8. 初始参数与判定

以下都是原型调试起点，不是已验证的平衡结果。

| 项目 | 初始值／约束 |
|---|---|
| 本关操作血量 | 4 格，进入本关独立初始化，不继承东岭关剩余血量 |
| 普通拒马／交互箭伤害 | 每次 1 格 |
| 受击保护 | 暂定 0.8 秒，期间不再次掉血或重复累计受击 |
| 拒马减速 | 暂定 0.6 秒；同一碰撞只施加一次减速及追击距离惩罚 |
| 单次换道 | 暂定 0.20 秒 |
| 常规障碍可辨认至到达 | 目标至少 1.5 秒；强制跨两道另加足够的换道余量 |
| 单箭锁定至危险到达 | 目标至少 0.9 秒；首轮示范至少 1.4 秒 |
| 阶段 A 成功追击 | 约 30–45 秒，路线暂定最长 65 秒 |
| 阶段 B 可操作冲刺 | 约 25–40 秒 |

玩家、拒马与箭在道路坐标中拥有横向范围、纵向位置及各自的伤害资格；同一投影配置驱动画面位置、缩放和判定区域。以马蹄地面锚点及实际横向移动计算碰撞，不能按贴图透明边框、刀尖或屏幕图片大小扣血。高速运动要检查跨帧经过的范围，不能因帧率变化穿过障碍。

全程计时区分可操作时间和演出时间，暂停／失焦／模态界面都停止推进。受击保护不会让拒马或箭的同一次攻击在保护结束后重新生效；它们通过玩家后只退场，不再次伤害。

## 9. 失败、检查点、保存与评价

### 9.1 检查点

- 完成教学后建立阶段 A 起点检查点；避障失败或孟坦逃脱默认“重追孟坦”，恢复 4 格血、初始距离和起点序列，不强制重看开场或重复已完成教学。
- 完成斩孟坦与暗箭演出后、阶段 B 第一轮瞄准前建立阶段 B 检查点。进入时恢复 4 格操作血量，负伤外观保留；检查点血量与伤态彼此独立。
- 阶段 B 失败默认“重试冲门”，恢复该检查点，不重新追孟坦、不重复斩孟坦或再中剧情箭。玩家也可明确选择从本关起点重开。
- 检查点仅属当前会话；退出本关或刷新后从本关起点开始，不持久化半场战斗。不得清除既有通关或最佳成绩。
- 恢复时重置位置、速度、换道与输入缓存、箭、拒马、瞄准状态、受击保护、动画、声音和状态转换锁，预留与首次进入相同的起跑安全时间。

### 9.2 失败与统计

操作血量归零或孟坦逃脱即锁定失败，后续危险和到达事件不再结算；短失败反馈后显示原因和重试入口。骑马失败反馈需要单独设计，不能直接套用步战倒地把马或关羽切断。失败演出也可暂停，并阻止重复按钮、键盘确认和输入穿透。

检查点记录成功路径的可操作时间、可避免受击数及必要阶段状态。重试丢弃失败尝试的时间／受击并恢复检查点快照，重试次数保留；阶段 B 重试保留已成功阶段 A 的统计。整关重开重置本局统计，不改历史成绩。

首版结算显示本关通关、成功路线时间、可避免受击和重试次数；剧情箭不计入受击，无伤指可操作阶段无受击。综合分数公式与奖章阈值待试玩后定，不沿用第一关击杀数公式冒充第二关评分。

### 9.3 旅图与持久化

本关标识沿用 `luoyang`。正式接入后，东岭关已通关且洛阳内容已开放才允许进入；开启洛阳不能顺带开启尚未交付的汜水关。开篇回顾和重玩不重复播放全游戏六幕前情。

当前 `progress_store.gd` 保留东岭关原分数接口，新增 `ch02-v1-route` 独立保存洛阳成功路线的时间、受击、重试与换道次数。以最快成功路线为最佳，同时间再比较受击／重试；不计算尚未定稿的综合分数。沿用现有 schema 1，保留旧设置、前情状态、东岭关成绩与未知字段，不清除或重置存档。

胜利锁定后按既有流程保存通关，再展示文化／结算；跳过演出、连续确认和返回旅图不得重复写入或漏存。保存失败清楚提示并允许继续查看结算，不能伪报保存成功。所有开发测试使用隔离临时存档。

## 10. 界面、声音与减少动态

- 沿用[全游戏武侠设计语言](wuxia-design-language-spec.md)：墨绿、旧金、朱红和现有字体体系，避免现代竞速仪表盘。
- 常驻只保留气血、暂停／声音入口，以及当前阶段必要的追赶或到门距离反馈。距离优先通过实体目标表达，原型确认不足时再加一条简洁指示；不叠加两个 Boss 血条、义气条和无用途分数。
- 换道键帽只在教学与必要的首次箭路示范短暂出现；不常驻大段说明。孟坦逃脱、血量归零和保存失败用清楚的文字说明。
- 马蹄、风声、碰撞、拉弓、放弦、箭掠过和挥刀分别提供节奏反馈。箭路同时有可视线索，静音也能玩；不能仅靠红绿颜色区分瞄准与锁定。
- 暂停、失焦及模态界面冻结道路、追击、箭、独立动画、尘土时间轴和音频。恢复前清除旧换道输入，不因界面确认键同时跳过演出或触发另一个按钮。
- 减少动态关闭震屏、强烈速度线、快速镜头推拉和装饰性闪光；保留游戏必需的道路移动、换道、箭与危险提示。特写可使用固定构图，不改变时机与难度。
- 新增汉字需检查三套现用字体的覆盖，必要时按既有方式扩充子集并保留旧字形。

## 12. Godot 实现边界与原型顺序

以下为建议模块划分，具体文件名在实现时确定；这里没有声称模块已经存在。

- 第二关建立独立关卡场景、会话控制器、道路投影与角色表现，入口由现有主流程路由。第一关战斗仍由原有模块负责，不将跑酷状态直接堆进第一关战斗分支。
- 建议状态顺序为开场、教学、追击、斩孟坦、暗箭、冲门、斩韩福、结尾／结算；失败与暂停单独控制。每段退出有唯一条件，伤害、跳过和重复信号不会造成重复转换。
- TSCN 保存相机构图参考、道路锚点、车道中心、门前收尾点、真实人物／建筑／界面节点及动画配置。运行时可以生成短暂箭矢和障碍实例，不用一个 Node2D 绘制整个关卡。

- 暂停与存档接入现有全局规则；第二关进度、成绩和检查点独立，第一关操作及战斗结算保持兼容。

建议按三个可验收步骤推进，不先批量补全全部素材：

1. **可读性原型：**用明确标注的占位角色和真实道路节点验证三车道、换道、透视、单拒马与单箭，实际检查编辑器和 Web；先确认看得清、来得及躲。
2. **完整玩法原型：**接入追赶距离、有限路线、阶段转换、剧情箭、两处检查点、失败重试与旅图入口，用隔离存档完成整关。
3. **美术与演出整合：**补匹配视角的骑乘动画、两次斩将、回马／负伤、声音及结尾，再调节时长与难度，完成视觉及实际试玩验收。

## 14. 初版操作原型（保留）

此前按用户授权完成第 12 节第一步，验证三车道换道、躲拒马及躲箭。入口为 `godot/scenes/prototypes/luoyang_prototype.tscn`；这三个独立练习仍保留，不接入旅图或正式进度。下述“不含追击／剧情”等边界只适用于此旧练习，不代表第 15 节完整玩法原型的现状。

- 三种入口：连续试跑（拒马 28 秒后进入箭矢 28 秒）、拒马练习、箭矢练习。开场有安全距离；没有强制左右教学、追孟坦距离、逃脱路线、剧情箭、双斩将、文化卡或正式成绩。
- 采用面向前路的后方伪透视构图；骑乘人物／赤兔、拒马、箭、射手及道路使用真实几何节点占位，现有洛阳城门原图作远景。尚未制作正式斜背面像素骑乘动画或完整美术，不以占位构图作为最终镜头验收。
- A/D 或左右换道，每次 0.20 秒，最多缓存一次后续换道，按住不连跳；R 重试本段，P/Esc 暂停，M 静音。菜单支持原生按钮、Tab／Enter；有减少动态开关，偏好不持久化。
- 四格操作血量；拒马／箭每次扣一格，0.8 秒受击保护。拒马造成 0.6 秒减速；道路锚点统一驱动位置与缩放，伤害按地面横向位置与纵向通过时刻判定。箭瞄准 1.10 秒、锁定停留 0.45 秒，再从纵深 88 以速度 72 飞来，锁定后不追踪。
- 固定拒马序列间隔 2.8 秒，箭轮间隔 3.4 秒。连续试跑进入箭段恢复四格血；重试箭段保留成功拒马段统计，丢弃失败箭段统计，重试次数累加。原型结算仅展示受击、换道和重试，不生成正式分数。
- 原型不引用进度存储模块、不读写存档、浏览器进度或设置。原生窗口失焦和 Web 的 blur／visibilitychange 都暂停；恢复不自动沿用旧换道缓存，新按键可立即生效。

运行与导出：在仓库根目录执行 `python3 tools/luoyang_prototype.py` 运行原生场景；执行 `python3 tools/luoyang_prototype.py --export` 生成独立单线程网页，再运行 `python3 tools/luoyang_prototype.py --serve --port 8972`，打开 [本机操作原型](http://127.0.0.1:8972/)。`--godot` 可指定 Godot 4.7.2。导出仅覆盖独立原型的固定输出，不覆盖 `builds/web/` 或 `builds/vercel/`，不自动公开发布。

本轮验证与待验收项见[洛阳原型验证记录](luoyang-prototype-qa.md)。本原型用于讨论手感，尚不能视为第二关整关交付。

## 15. 当前完整玩法原型

本节是第二步完成时的实现快照。当前美术已继续整合，见第 16 节；下文“几何占位／尚无像素动作”不代表最新状态。

用户认可初版手感后，继续完成第 12 节第二步。入口为 `godot/scenes/levels/luoyang_chapter.tscn`；`luoyang_chapter_model.gd` 管完整会话，`luoyang_chapter.gd` 管表现与宿主信号，复用原练习的换道、危险与道路投影代码。完整关卡拥有独立真实 TSCN 布局，未使用继承场景的局部控件覆盖，避免导出后布局位置重置；角色／武器／特写仍为几何占位。

### 15.1 已接通流程

开场 → 低压左右换道教学 → 追孟坦 → 自动斩孟坦 → 回马与暗箭 → 带伤冲门 → 自动斩韩福 → 束伤前行 → 文学改编回顾 → 结算。剧情可用 Enter／按钮继续，连续按键不会一次跨过多个状态；切入新段有输入保护。教学不扣血、不计成绩时间，完成两方向的实际换道后建立追击检查点。

- 追击初始道路距离 78、追上距离 10，正常每秒缩短 2；撞拒马每次额外拉开 20，并保留 0.6 秒减速。无伤约 34 秒追上。有限路线 65 秒，最后 8 秒提示岔口和逃脱风险；仍未追上则先播失败反馈，再开放重试。
- 孟坦以真实占位骑乘节点显示在前方，距离缩短时投影变大、靠近；接近追上时停止继续布置拒马，转场清除所有危险。
- 斩孟坦、回马暗箭及斩韩福使用独立侧面几何特写。暗箭演出显示箭与左臂束布，不扣操作血、不计可避免受击，逻辑结算恰好一次；跳过演出也会正确应用伤态。
- 冲门阶段 32 秒，首轮瞄准额外放慢 0.5 秒，后续沿用 1.10 秒瞄准、0.45 秒锁定与固定箭路；城门随进度逼近。到门与同一逻辑时刻的箭命中同时发生时，胜利优先；更早已经失败的尝试不能被到门事件翻转。
- 追击、冲门及本关总成功路径统计独立。每段重试恢复四格血、位置、输入、危险与该段起点；丢弃失败段统计，保留重试次数，冲门重试保留已成功追击和一次负伤状态。
- 剧情、失败反馈、换道及箭矢均可暂停；原生和 Web 失焦处理复用既有模式。故事回顾停留等玩家确认，转场保护到时后鼠标按钮与 Enter 均可用。

### 15.2 旅图与保存

本机 `chapters.json` 将洛阳标记为可进入的原型内容，仍需先通关东岭关。主流程只负责进入／返回、偏好和保存，第一关战斗模块不执行跑酷机制。进入第二关时停用并隐藏第一关场景与 UI，恢复可见系统鼠标；返回时恢复旅图与原刀形光标响应。

击败韩福锁定胜利时由宿主保存通关与独立路线成绩，不等待阅读文化卡或结算。第一次通过时旅图盖洛阳章、队伍到 `TravelLuoyangEnd`，右侧显示最快时间；汜水关及后两站继续不可进入。设置保存沿用旧字段，不覆盖东岭关成绩。保存错误显示在本关底部，仍可查看结算；独立试玩不连接宿主，不读写正式存档。

## 17. 孟坦随路避障与横移

根据用户试玩反馈，追击目标不再固定在右道：孟坦与玩家使用同一批道路坐标、拒马和透视锚点，由独立 `luoyang_pursuer.gd` 会话模型管理连续横向位置。每次换道0.55秒，提前48道路单位检查最近一排拒马，选择最近的真实空道；双道封锁时走剩余一侧。通过后再等7单位的马后间距，避免刚过脚底就横穿拒马。

敌将避障不消耗、清除或替玩家判定拒马，不占用玩家车道碰撞，不要求玩家与敌将同道才自动斩将。暂停／失焦及剧情冻结规划和横移；追击检查点重试重置路径。表现复用已有4帧奔跑，仅加轻微身体侧倾，没有新增独立转向图集；减少动态保留必要横移并关闭侧倾。实际画面位置直接来自该模型，已移除表现层固定车道覆盖。

## 20. 追逐、拒马与箭阵节奏精修（2026-11-27）

本节取代第15／17节的等间隔危险及首箭额外年龄偏移，延续第19节的65秒追逐上限、32秒冲门和21单位拒马惩罚。目标是让玩家先观察并掌握换道，再处理组合，最后从较慢首箭过渡到稳定的后段节拍；不是增加新操作。实现参数集中于 `luoyang_pacing.gd`。

### 20.1 追逐与拒马

- 保留0.20秒换道、一次缓存、四格血、单次扣一格及0.8秒保护。前段三个单道拒马依次封中／左／右；随后以双道封锁与单道交替，每组三排后留较长间隔。全程始终有安全车道，孟坦仍提前避开与玩家共享的同一排拒马。
- 生成时刻按追逐段秒数编排；以下每个分号为一组，括号内为封锁车道：`1.4(中)、4.8(左)、8.2(右)；12.3(左中)、15.1(中)、17.9(中右)；21.9(左右)、24.5(右)、26.7(左中)；30.8(中右)、33.4(中)、36.0(左右)；40.0(左)、42.6(中右)、45.2(左中)；49.2(中)、51.8(左右)、54.4(右)`。生成纵深仍为 `max(88, gap+48)`，时刻不等于到达马蹄判定线的时刻。
- 相距不超过24时不再生成新拒马，但仍消费已到时的编排。之后因撞击拉远距离，只会继续未来的排次；修正旧实现把已跳过排次积压、恢复后连续补刷的问题。
- 每次撞击仍额外拉开21单位：立即3，其余18在0.6秒恢复期内逐步拉开，同时保留原55%速度减速。孟坦不再一次跳远；暂停冻结未完成的拉远，重追清空它。
- 测量无伤追上约34.01秒、经过9排；一／两次指定碰撞后约44.78／55.54秒追上；三次碰撞后65秒仍剩1血并逃脱。拒马通过判定线的最小排间隔在所测路线中为无伤2.2秒、受击路线约2.0秒。按可辨认纵深55后延迟450ms行动，从三条起始道在120／15FPS均可无伤通过；这属于反应预算模拟，不替代新玩家难度反馈。

### 20.2 躲箭
