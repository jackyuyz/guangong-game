# 关公朱砂图标 · 2026-11-25

`guan-seal-icon.png`由内置OpenAI imagegen生成，1254×1254 PNG，朱砂红底、米白简体“关”字与细印章边框。生成文件原样复制，未覆盖源素材；完整提示与原始生成路径见[icon-creation.json](icon-creation.json)。用于本课程游戏的项目品牌，不声称历史印章复原。
