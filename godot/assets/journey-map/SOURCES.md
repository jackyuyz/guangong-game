# 五关旅图素材

制作日期：2026-11-22。地图为《关公 · 过五关斩六将》的文学旅程示意。

- `five-passes-scroll.png`：使用内置 image_gen 生成的 1672×941 完整像素山水卷轴。木轴、纸张、道路、东岭山口、洛阳城、汜水寺院、荥阳驿馆和黄河渡口统一构图；右侧纸面留给动态题记，图片没有关名或按钮文字。
- 风格参考：工程已有 `../prologue/frames-v2/05-escort.png`，只参考像素质感、配色与光照，不复制其人物构图。完整提示词与生成方式见 [creation.json](creation.json)。
- 原始生成文件为 `exec-1a71a074-ccef-4962-bf84-b0056666267f.png`，保留于本机 Codex 的 `generated_images/01a1ef8d-02f7-7213-8d96-1388e2885ef6/`。运行 PNG 为原文件复制，未做程序修图；源素材库未覆盖或删除。
- 地图队伍复用工程的 `../guan-yu.png` 与 `../carriage.png`，来源见上级 [SOURCES.md](../SOURCES.md)。两者作为可编辑 Sprite2D 配合共同落地阴影，以较小比例站在旅路上；队伍位置由真实进度决定，与选中节点无关。
- 纸张声音复用 `../prologue/audio/paper.wav`，为项目已有的原创合成拟音；没有新配音生成请求。地图上无叙事旁白，前情回顾继续使用现有六段本地录音。
- 关名、状态、详情、按钮、通关印章、路线、朱红镶金军旗和选中金色笔触均为 Godot 原生节点。军旗与笔触用可编辑 Polygon2D / Line2D 制作，没有新增生成图片；军旗表示实际位置，选中笔触位于关名下，节点没有矩形选择框。关名为 22px 深墨色配 4px 暖米色描边，与较小的状态字分层，提升山水背景上的可读性。`../demo-font.ttf` 补齐新增运行文字，沿用 `../FONT-LICENSE.txt` 的 SIL OFL 许可。

地图场景在 `res://scenes/ui/journey_map.tscn`，最近邻采样。展开、旗帜呼吸轨道可在编辑器中查看；减少动态时直接呈现终态。生成提示记录与本说明不导入运行导出包。
