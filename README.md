# 关公 · 过五关斩六将

课程合作项目：制作关公故事互动游戏，并通过网页提供访问入口。
游戏准备使用 Godot 开发，最终导出 Web 版本。

已有五关美术素材、玩法设计，以及第一关「东岭关」的 Godot 可玩 demo。

第二关[洛阳完整玩法原型](docs/design/chapter-02-luoyang-spec.md#21-与首页东岭关统一界面及正式网页流程2026-11-27)已接入本机源码：通关东岭关后可从旅图进入，包含追孟坦、暗箭负伤、冲门斩韩福、检查点与独立路线记录；像素骑乘、双斩将、回马／城门衔接、岔口逃脱及束伤车仗离关已整合，马车造型按第一关统一；拒马分组与渐进箭阵已精修，界面与首页／东岭关统一，正常网页通关保存及返回流程已用隔离进度验证；2026-11-27已随完整首页版本发布到Vercel，未做线上试玩。独立免存档试玩运行 `python3 tools/luoyang_prototype.py --chapter`；网页加 `--chapter --export` 导出、`--chapter --serve` 启动，默认 [本机8973](http://127.0.0.1:8973/)。原三个操作练习继续保留。

默认启动始终进入完整游戏首页，再按前情、旅图和已解锁关卡推进。独立8973及旧练习入口仅供开发验证，不在正常游戏菜单中提供，也不作为正式发布入口。

## 试玩第一版

本机已导出时，双击根目录的 `play-web.command`，或运行 `python3 tools/serve_demo.py`，打开 <http://127.0.0.1:8765/>。保持服务终端运行；这是本地试玩地址，公开版本使用上方 Vercel 链接。

使用 **A/D 或左右键**移动，**J** 挥刀（连按最多三段），**Space** 闪避，**K** 格挡/弹反，**L** 义气偃月斩，**E** 茶摊互动，**Enter** 推进对白，**Esc/P** 暂停，**M** 切换声音。

五关卷轴地图可查看旅程进度、选择已解锁关卡开始或重玩。当前版本先开放东岭关，通关后开放洛阳原型；后三站仍以淡墨和薄雾表示不可进入。正式网站已更新为此版本。地图可「回顾前情」，返回时保留原选择。声音、减少动态和完整键位位于设置与操作指南。

前情右上角可切换声音，“更多”中可重听本幕；浏览器若阻止声音，会先提示“开启声音／静音观看”。

流程：首次六幕中文说书前情（约 51 秒，可跳过） → 五关旅图选关 → 到旗标／两刀开路／向右闪避教学 → 前行迎敌 → 两波守军 → 孔秀两阶段战斗 → 文化回顾与结算。Boss 战失败可直接从检查点重试。设置、通关及最佳分数保存在本机；临时检查点退出后清除。

这是验证画面与手感的原型：现有像素人物搭配东岭关完整背景，已接入基于现有素材生成的走路/攻击帧，部分姿态复用图集帧；已有开篇中文说书配音，尚无多语言和战斗对白配音；洛阳已在本机整合完整流程与骑乘美术，其余三关尚未实现。东岭关已拆为远景、世界固定关口、连续道路与低矮前景，保留原人物与独立城门／墙段／树木；教学区分段限行，需两刀开路并完成向右闪避后才能前行迎敌，尚未加入示范突刺。

在本机用 Godot 打开工程并试玩，见 [本地 Godot 运行](docs/local-godot.md)：安装 4.7.2，导入 `godot/project.godot`，按 F5。Web 使用 `godot/export_presets.cfg` 的单线程 Web 预设导出到 `builds/web/index.html`。详情见 [工程说明](godot/README.md)。

## Godot 和网页的关系

Godot 工程放在本仓库的 `godot/` 目录，无需另外创建仓库。
`godot/project.godot` 是编辑器入口，`res://` 对应 `godot/`。
开发时使用 Godot 编辑器；发布时导出 Web 文件，再上传到网站供大家点链接游玩。

`assets/art/` 是素材库，`docs/art/` 是查阅用的展示图。
选中实际要用于游戏的图片后，复制到 `godot/assets/`，再由 Godot 导入；不要直接导入全部展示图。
素材路径和索引保持原样，便于追溯来源。

网页导出文件放在 `builds/web/`，已加入 Git 忽略列表。文化网站尚未创建。

重新导出可双击 `export-web.command`，或运行 `python3 tools/export_web.py`。
工具覆盖固定的 `builds/web/` 并准备 `builds/vercel/` 正式发布目录，不自动上传。
Vercel 登录、关联项目及手动更新步骤见 [组员部署操作手册](docs/vercel-deploy.md)。
Git 推送仅同步源码；根 `vercel.json` 关闭 Git 自动部署，网页仍按上述流程手动发布。
